# lc-analysis

By [@glaroton](https://github.com/glaroton).

**Differential and integral calculus on locally convex spaces, formalized in Lean 4 and Mathlib.**

API documentation (generated by doc-gen4): <https://glaroton.github.io/lc-analysis/docs/>

Blueprint (the mathematics in the usual language, each result linked to its Lean proof, with a
dependency graph): <https://glaroton.github.io/lc-analysis/blueprint/>, also as a
[PDF](https://glaroton.github.io/lc-analysis/blueprint.pdf). Its source is in
[`blueprint/src`](blueprint/src).

This library formalizes the *Michal–Bastiani* calculus [Mic38; Bas64] (Keller's `C^k_c`
[Kel74]). It is the usual foundation for infinite-dimensional Lie theory and global analysis,
where manifolds and Lie groups are modeled on arbitrary locally convex spaces: Fréchet spaces of
smooth functions, spaces of test functions, direct limits. Mathlib's differential calculus
(`HasFDerivAt`, `ContDiff`) is built on normed spaces, so it does not cover these models.

There is no `sorry`. The main theorems depend only on Lean's standard axioms `propext`,
`Classical.choice` and `Quot.sound`; the [Verification](#verification) section explains how to
check this.

## The setting

Let `E`, `F` be real locally convex Hausdorff spaces, `U ⊆ E` open and `f : U → F`.

* **Differentiability.** `f` is `C^1` if every directional derivative
  `df(x)(h) = lim_{t → 0} t⁻¹ (f (x + t h) - f x)` exists and `df : U × E → F` is continuous. It is
  `C^{k+1}` if moreover `df` is `C^k`.
* **Tools in place of norm estimates.** Hahn–Banach: continuous linear functionals separate points
  from closed convex sets. Local convexity: closed convex neighborhoods of `0` form a basis.
* **Integrals.** Integrals of curves are *weak* integrals: `y = ∫_a^b γ` means
  `φ y = ∫_a^b φ (γ t) dt` for every continuous linear functional `φ`. They are unique, but they
  need not exist. They do exist under mild completeness conditions on `F`.

### Locally convex subsets with dense interior — [`Calculus/DenseInterior/Basic.lean`](LocallyConvexAnalysis/Calculus/DenseInterior/Basic.lean), [`Calculus/DenseInterior/Rules.lean`](LocallyConvexAnalysis/Calculus/DenseInterior/Rules.lean), [`Calculus/DenseInterior/Ckl.lean`](LocallyConvexAnalysis/Calculus/DenseInterior/Ckl.lean), [`Calculus/DenseInterior/CklRules.lean`](LocallyConvexAnalysis/Calculus/DenseInterior/CklRules.lean), [`Calculus/DenseInterior/ExpLaw.lean`](LocallyConvexAnalysis/Calculus/DenseInterior/ExpLaw.lean)

boundary [GN26, 3.5.1]. A subset `U ⊆ E` is locally convex if each point has a convex neighborhood
in `U`; `f` is `C^1` on `U` if it is `C^1` on the interior `U⁰` and `d(f|U⁰)` extends
continuously to `U × E`. No completeness is assumed.

elements of the target and checked seminorm by seminorm, so no completion is used.

### Krein spaces — [`Krein/OrthoComplemented.lean`](LocallyConvexAnalysis/Krein/OrthoComplemented.lean), [`Krein/SpectralParts.lean`](LocallyConvexAnalysis/Krein/SpectralParts.lean), [`Krein/Majorant.lean`](LocallyConvexAnalysis/Krein/Majorant.lean), [`Krein/IntrinsicDimension.lean`](LocallyConvexAnalysis/Krein/IntrinsicDimension.lean), [`Krein/Perturbation.lean`](LocallyConvexAnalysis/Krein/Perturbation.lean), [`Krein/HilbertComplexification.lean`](LocallyConvexAnalysis/Krein/HilbertComplexification.lean)

Moved here from lc-manifolds on 2026-11-10 (it is linear analysis); lc-manifolds applies it to
fields of projectors on submanifolds of a Krein space.

* Ortho-complemented subspaces of a Krein space `(H, ⟪J ·, ·⟫)`, `H` a Hilbert space and `J` a
  fundamental symmetry, with Bognár's algebraic notion of Krein space (fundamental decomposition
  into intrinsically complete parts) [Bog74]. An ortho-complemented subspace (`L + L^[⊥] = H`) is
  closed and nondegenerate; it is ortho-complemented iff its Gram operator `P_L J|_L` is
  bijective, iff it has a continuous `J`-orthogonal projector. **[Bog74, Theorem V.3.4]**: a
  subspace is ortho-complemented if and only if it is closed and a Krein space with the restricted
  form (`FundamentalSymmetry.isOrthoComplemented_iff_isClosed_and_isKreinSpace`, over `ℝ` and
  `ℂ`; "if" by the closed graph and Riesz theorems, "only if" by the spectral projections of the
  Gram operator, `FundamentalSymmetry.exists_spectral_projection`, through the complexification
  over `ℝ`). A positive definite subspace is ortho-complemented iff it is closed and uniformly
  positive (`FundamentalSymmetry.isOrthoComplemented_iff_uniformlyPositive_of_posDef`).
  **[Bog74, Theorem V.3.1]**: every closed subspace has a fundamental decomposition
  `L = L⁰ ∔ L₊ ∔ L₋` (`L⁰` the isotropic part) whose components and sums of any two of them are
  closed (`FundamentalSymmetry.exists_fundamentalDecomposition_of_isClosed`); Bognár uses the
  spectral function of the Gram operator, here `ker G`, `(ker G⁺)^⊥`, `(ker G⁻)^⊥` with `G^±`
  from the continuous functional calculus suffice (`FundamentalSymmetry.exists_sign_decomposition`,
  over `ℝ` and `ℂ`). **[Bog74, Theorem V.3.5]**, as stated there: `L` is ortho-complemented iff it
  is closed, nondegenerate, and every fundamental decomposition of `L` extends to one of `H`
  (`FundamentalSymmetry.isOrthoComplemented_iff_isClosed_nondegenerate`).
* [`Krein/Majorant.lean`](LocallyConvexAnalysis/Krein/Majorant.lean): **the majorant topology**.
  Each fundamental decomposition `E = E₊ ⊕ E₋` has its `J`-inner product
  `[x, y]_J = B(P₊ x, P₊ y) - B(P₋ x, P₋ y)`. In a Krein space (algebraic sense, no topology
  given) the space of a Krein decomposition with its `J`-norm is a Hilbert space
  (`KreinDecomposition.completeSpace`), **all decomposition majorants coincide**
  (`KreinDecomposition.exists_jInner_bounds`; [Bog74, Theorem IV.6.4, Corollary IV.6.3]), and
  **every fundamental decomposition is a Krein decomposition** (`KreinDecomposition.ofAlg`;
  [Bog74, Theorem IV.7.2]). On a Hilbert space with invertible self-adjoint Gram operator, every
  fundamental decomposition has closed components, a continuous fundamental symmetry and a `J`-norm
  equivalent to the norm (`AlgFundamentalDecomposition.exists_jInner_bounds`). Bognár's iteration
  for Theorem 6.4 is replaced, for Krein spaces, by the positivity and invertibility of `G J`.
* [`Krein/IntrinsicDimension.lean`](LocallyConvexAnalysis/Krein/IntrinsicDimension.lean): **the
  intrinsic dimension** (dense-span dimension of a definite component with its intrinsic norm). For
  two fundamental decompositions of a Krein space, `P₁₊ : E₂₊ ≅ E₁₊` is an isomorphism of
  topological vector spaces (`KreinDecomposition.posEquiv`; [Bog74, Lemma IV.7.1]); hence the
  **rank of positivity and the rank of negativity** (the index) do not depend on the decomposition
  (`KreinDecomposition.intrinsicDim_pos_eq`, `KreinDecomposition.intrinsicDim_neg_eq`; [Bog74,
  Corollary IV.7.4]). These ranks are the Hilbert dimensions of `E₊` and `E₋`
  (`KreinDecomposition.intrinsicDim_pos_eq_card`): in an inner product space, no orthonormal family
  is larger than a set with dense span, so the dense-span dimension is the cardinality of any
  Hilbert basis (`Orthonormal.cardinal_le_denseSpanDim`, `HilbertBasis.denseSpanDim_eq`).
* [`Krein/Perturbation.lean`](LocallyConvexAnalysis/Krein/Perturbation.lean): **continuous
  families of Krein spaces**. For a norm-continuous family `G(x)` of invertible self-adjoint
  operators on a real or complex Hilbert space, the spectral projections onto the positive part
  depend continuously on `x` (`exists_continuous_spectral_projection`; continuous functional
  calculus and upper hemicontinuity of the spectrum, over `ℝ` through the complexification), so
  fundamental decompositions can be chosen continuously; kernels of orthogonal projections at
  distance `< 1` are isomorphic (`continuousLinearEquiv_ker_of_norm_sub_lt_one`); and **the index
  is locally constant**, whatever fundamental decompositions are chosen (`isLocallyConstant_index`).
* `HilbertComplexification`: the complexification `E × E` of a real (or complex) inner product
  space, a complex inner product space, complete if `E` is, with complexified operators and the
  conjugation; used to bring the continuous functional calculus to real Hilbert spaces. (Not to
  be confused with `Complexification`, the complexification of a real locally convex space used
  for real analytic maps.)

### Counterexamples — [`Counterexamples/`](LocallyConvexAnalysis/Counterexamples)

Results of calculus that hold in normed or Banach spaces and fail in locally convex spaces, each
with a formalized counterexample (namespace `LocallyConvex.Analysis.Counterexamples`).

* [`Counterexamples/Units.lean`](LocallyConvexAnalysis/Counterexamples/Units.lean): the units of a
  Banach algebra form an open set (`isOpen_isUnit`); those of the Fréchet algebra `C(ℝ, ℝ)` do not
  (`not_isOpen_isUnit_continuousMap`).
* [`Counterexamples/ODEUniqueness.lean`](LocallyConvexAnalysis/Counterexamples/ODEUniqueness.lean):
  uniqueness for linear equations `y' = A y` in normed spaces (`linearODE_eq_zero`); a nonzero
  solution with `y(0) = 0` for the left shift on `ℝ^ℕ` (`exists_linearODE_ne_zero`) [Ham82].
* [`Counterexamples/ODEExistence.lean`](LocallyConvexAnalysis/Counterexamples/ODEExistence.lean): in
  Banach spaces `y' = A y`, `y(0) = y₀` has the solution `exp(t A) y₀`
  (`exists_linearODE_solution`); on the Fréchet space `s`, `y' = D y` with `D x = (n² xₙ)` has no
  solution on any `[0, ε)` for `y(0) = (e^{-(n+1)})` (`RapidDecay.not_exists_linearODE_solution`):
  the backward heat equation on `C^∞(S¹)` on the Fourier side [Mil84; Nee06, Ex. II.3.12].
* [`Counterexamples/LocalBoundedness.lean`](LocallyConvexAnalysis/Counterexamples/LocalBoundedness.lean):
  complex analytic maps into normed spaces are locally bounded (`ComplexAnalyticOn.exists_bounded`);
  `g(x) = (f((k + 1) x))ₖ`, with `f(x) = ∑ₖ 2^{k+1} x_k^{2k+2}` on `ℓ¹`, is a complex analytic map
  `ℓ¹ → ℂ^ℕ` whose image of every `0`-neighbourhood is unbounded
  (`exists_complexAnalyticOn_not_bounded`; [GN26, Exercise 2.1.10]).
* [`Counterexamples/FrobeniusFails.lean`](LocallyConvexAnalysis/Counterexamples/FrobeniusFails.lean):
  on `s`, the rank-one (hence involutive) distribution `x ↦ ℝ · D x`, `D x = (n² xₙ)`, has no
  tangent curve through `(e^{-(n+1)})` (`RapidDecay.not_exists_integral_curve`; [KM97, 32.12,
  Example 1]); in Banach spaces involutive split distributions are integrable
  (`Frobenius/Basic.lean`).
* [`Counterexamples/InverseFunction.lean`](LocallyConvexAnalysis/Counterexamples/InverseFunction.lean):
  in Banach spaces a map with strict derivative the identity at `a` is open at `a`
  (`image_mem_nhds_of_hasStrictFDerivAt`); on the Fréchet space `ℝ[[x]] ≅ ℝ^ℕ` the map `P(f) = f - x
  f f'` is smooth with `P(0) = 0` and `dP(0) = id`, but its image is not a neighbourhood of `0`
  (`exists_smooth_not_open`; [Ham82, Counterexample 5.5.1]).
* [`Counterexamples/BoundedBelowStability.lean`](LocallyConvexAnalysis/Counterexamples/BoundedBelowStability.lean):
  in normed spaces, if `(t, v) ↦ L(t) v` is `C¹` and `L(0)` is a topological embedding, the
  operators `L(t)` are bounded below with a common constant for `t` near `0`
  (`exists_uniform_boundedBelow`); on the Fréchet space `s` of rapidly decreasing sequences, a
  smooth family of diagonal isomorphisms with `L(0) = id` has inverses that are not equicontinuous
  near `0` (`RapidDecay.counterexample`).
* [`Counterexamples/ReflectSmoothness.lean`](LocallyConvexAnalysis/Counterexamples/ReflectSmoothness.lean):
  in Banach spaces a smooth map whose derivative is bounded below at every point reflects smoothness
  of continuous curves (`Calculus/BoundedBelow.lean`); on `ℝ × s` a smooth bijection whose
  derivative is a linear automorphism at every point maps a continuous curve that is not `C¹` to an
  affine one (`RapidDecay.not_reflect_smoothness`).
* [`Counterexamples/WeakDarboux.lean`](LocallyConvexAnalysis/Counterexamples/WeakDarboux.lean): by
  the Darboux–Weinstein theorem a strong symplectic form on a Banach space is constant in suitable
  charts [Wei69] (formalized in lc-manifolds, `Darboux.exists_darboux_local`); Marsden's weak
  symplectic form on `ℓ² × ℓ²` [Mar72] is smooth, closed and weakly nondegenerate, but admits no
  Darboux chart at the origin (`Marsden.no_darboux_chart`), not even a vector bundle chart of the
  fibers (`Marsden.no_vector_bundle_chart`, the referee's remark in [Mar72]); its diagonal operator
  is compact with dense range (`Marsden.L2.isCompactOperator_S`, `Marsden.L2.denseRange_S`).
* [`Counterexamples/BognarKrein.lean`](LocallyConvexAnalysis/Counterexamples/BognarKrein.lean):
  **[Bog74, Example V.3.3]** (with Example I.9.7): in `ℓ²` with `J = diag(-1, 1, -1, 1, …)`, the
  subspace `{x | x_{2k+1} = (2k + 2)/(2k + 1) x_{2k}}` is closed, positive definite, nondegenerate
  and decomposable, but not intrinsically complete, not a Krein space and not ortho-complemented
  (`BognarKrein.bognar_example`): in Hilbert spaces closed subspaces are complemented, in Krein
  spaces closed nondegenerate subspaces need not be ortho-complemented.

The counterexamples in `BoundedBelowStability.lean` and `ReflectSmoothness.lean` have no source
that we know of; they are in the spirit of [Ham82, Part I, Counterexamples 5.3.3 and 5.5.3]. We do
not claim that they are new. The selection of results is ours; corrections and missing items are
welcome.

## Design decisions

* **Michal–Bastiani, not convenient calculus.** Convenient calculus [KM97] is the other standard
  framework for infinite-dimensional analysis. It agrees with Michal–Bastiani calculus on Fréchet
  spaces but not in general. This library follows the Michal–Bastiani framework of the Lie theory
  in [Nee06; GN26], which it is meant to support.
* **A recursive definition of `C^k`.** `ContDiffMBOn (k + 1) f U` means that `f` is `C^1` on `U`
  and `dMB f` is `C^k` on `U ×ˢ univ`. This makes induction on `k` straightforward, for instance in
  the chain rule and for parameter-dependent integrals. Bastiani's original definition, continuity
  of all iterated directional derivatives, is `HasContIterDerivOn`, and the two are proved
  equivalent.
* **One universe for domains.** `ContDiffMBOn` is defined by recursion on `k` and quantifies over
  domains. As a consequence, the domains of `C^k` maps live in a fixed universe `u`. Codomains are
  unrestricted.
* **Existence of integrals is a hypothesis, not an assumption on the space.** `HasWeakIntegral γ a b
  y` is a relation, so results hold in every locally convex space under explicit existence
  hypotheses, and completeness enters only through the existence theorems. The function
  `weakIntegral`, with junk value `0`, is used only where existence is known.
* **Completeness without uniform structures.** `SeqComplete` and `MackeyComplete` are stated
  through the topology: a sequence is Cauchy when `u n - u m` is eventually in every neighborhood
  of `0`. This avoids fixing a uniform structure on a topological vector space. For a uniform
  additive group, `CompleteSpace` implies `SeqComplete`.
* **Mackey completeness through Mackey–Cauchy sequences.** `MackeyComplete` asks every Mackey–Cauchy
  sequence to converge: `u l - u k ∈ r k • B` for `k ≤ l`, with `B` bounded and `r k → 0`. This is
  one of the equivalent characterizations in [GN26, 1.1.18(e)] and [KM97, 2.2, 2.14]. It is the more
  convenient form for the existence proofs. The definition of [GN26, 1.1.17(b)], that Lipschitz
  curves have weak integrals, is `IntegratesLipschitzCurves`, and the two are proved equivalent
  (`mackeyComplete_iff_integratesLipschitzCurves`).
* **Mathlib conventions.** File layout, naming, docstrings and the linter set follow Mathlib.

## What is new here and what is not

**The mathematics is not ours.** Every theorem in this library is known and appears in the
literature. Each file and the blueprint cite the source of each result, with theorem and page
numbers checked against the source wherever we could consult it.

**Where the formal proofs depart from the cited sources.** In a few places the Lean proof does not
follow the argument of the source we cite for the statement, usually because a route through
results already in Mathlib was shorter to formalize. We list them so the reader can compare.
We do not claim these arguments are new: we have not searched the literature systematically, and
most of them are probably standard or appear elsewhere. We will gladly add a reference for any
of them.

* Parameter-dependent integrals: all the results come from a single induction, whose hypothesis
  is that every `C^m` map on `U × T` has weak integrals in the second variable; the sequentially
  complete and Mackey complete cases are corollaries.
* Weak integrals are constructed as limits of dyadic Riemann sums, with the Cauchy estimate from
  uniform continuity (continuous case) or from the mean value inclusion (`C^1` case).
* Converse of `mackeyComplete_iff_integratesLipschitzCurves`: a Mackey–Cauchy sequence is turned
  into a Lipschitz curve by placing the increments of a fast subsequence on tents supported on
  `[1 - 2⁻ʲ, 1 - 2⁻ʲ⁻¹]`. This is a Lipschitz variant of the polygon through a fast falling
  sequence used in [KM97, Lemma 2.8 and the proof of Theorem 2.14, pp. 20–21].
* The second part of the fundamental theorem is reduced, by an affine change of variables, to the
  estimate for integrals of small curves.
* Hartogs' lemma for vector-valued holomorphic families (`Analytic/HartogsLemma.lean`): [BS71b]
  obtain the needed uniformity from Siciak's polynomial lemma, which rests on potential theory;
  here it comes from Jensen's formula, already in Mathlib.
* Continuity of superposition operators on `C^k(U, E)` (`MappingSpace/CkTopology.lean`; [GN26, Prop.
  1.7.12]): [GN26] uses Faà di Bruno's formula. Here the proof is an induction on `k`, from an
  explicit formula for the differentials of `dγ` in terms of those of `γ` (via Schwarz's theorem),
  which makes `d : C^{k+1}(U, F) → C^k(U × E, F)` continuous, and from the chain rule `d(f ∘ (id,
  γ))(x, v) = df((x, γ x), (v, dγ(x, v)))`. Pullbacks along `C^r` maps (Proposition 1.7.11, also
  proved there with Faà di Bruno's formula) are treated by the same induction, from `d(γ ∘ f)(x, v)
  = dγ(f x, df(x, v))`.
* Closed image of `C^k(U, F)` in `∏_{j ≤ k} C(U × E^j, F)` ([GN26, Lemma 1.7.15]): their
  proof uses Exercise 1.1.13(b) on limits of `C^1` curves, whose hint goes through weak
  integrals; here the limit is differentiated with the mean value inclusion (Hahn–Banach), with
  no completeness assumption.
* Mixed partial derivatives (`hasDirDerivAt_comm`; [GN26, Lemma 1.3.16]): instead of
  differentiating a weak integral in a completion, the difference quotients are differentiated
  and the limit is taken with the mean value inclusion, so no completeness is needed.
* Exponential law for `C^{k,ℓ}` maps (`Calculus/ExponentialLaw.lean`; [GN26, Thm. 1.7.30]):
  the differentiability of `f^∨` comes from the uniform convergence of difference quotients on
  compact sets and Bastiani's characterization of `C^k`; the embedding, from the continuity of
  evaluations on compact sets; and the surjectivity for locally compact `E₂`, from an explicit
  formula for the mixed differentials of `(x, y) ↦ g(x)(y)`, instead of the evaluation map and
  the chain rule for `C^{r,s}` maps with Faà di Bruno's formula.
* `C^{k,k}` maps are `C^k` (`Calculus/SmoothExponentialLaw.lean`; [GN26, Prop. 1.7.33(b)]):
  instead of the explicit formula (1.108) for `d^(m) f`, an induction on the recursive definition
  of `C^k`, through the rule on partial differentials and explicit formulas for the mixed
  differentials of `((x, a), (y, b)) ↦ d^(1,0) f(x, y, a) + d^(0,1) f(x, y, b)`; the continuity
  of the inclusion follows by the same induction. The formula (1.108) is then proved afterwards
  (`Calculus/CklSchwarz.lean`), by expanding the multilinear map `d^(m) f(x, y, ·)`.
* Maps with uniformly injective derivative (`Calculus/BoundedBelowLC.lean`): we found no source for
  the locally convex statement. Its proof adapts the Banach one (`Calculus/BoundedBelow.lean`): the
  difference quotients are bounded by the mean value inclusion and the hypothesis on closed convex
  combinations of derivatives, the second order term is controlled by a bilinear seminorm bound for
  `d²j`, and limits come from sequential completeness. The hypothesis is automatic in normed spaces,
  and it cannot be weakened to pointwise embeddings: in the Fréchet space of rapidly decreasing
  sequences there is a smooth bijection with invertible derivative everywhere that does not reflect
  `C¹` (`Counterexamples/ReflectSmoothness.lean`). We do not claim the statement is new.
* Mean value theorem on locally convex subsets with dense interior
  (`Calculus/DenseInterior/Basic.lean`; [GN26, Prop. 1.4.8]): [GN26] proves the convex case with an
  integral in a completion of `F` and the general case by splitting the segment into pieces lying in
  convex neighborhoods. Here the convex case uses weak integrals, shrinking the segment towards an
  interior point and passing to the limit in a parameter-dependent integral; it yields the extension
  of difference quotients (Lemma 1.4.9), from which the general case follows by the fundamental
  theorem of calculus on `[0, 1]` with one-sided derivatives.
* Sufficiency in [GN26, Lemma 1.4.5] (`Calculus/DenseInterior/Rules.lean`): instead of the version
  of Lemma 1.3.12 for sets with dense interior (Remark 1.4.12), an induction on `k` through the
  explicit formula for the differentials of `d(f|U⁰)` in terms of those of `f|U⁰`.
* Chain rules for `C^{r,s}` maps (`Calculus/DenseInterior/CklRules.lean`; [GN26, Props. 1.7.26
  and 1.7.28]): instead of Faà di Bruno's formula for the mixed differentials, a recursive
  characterization of `C^{k,ℓ}` through the partial differentials `d^(1,0) f` and `d^(0,1) f`, and
  induction from the chain rule for `C^k` maps.
* Exponential law on sets with dense interior (`Calculus/DenseInterior/ExpLaw.lean`; [GN26, Thm.
  1.7.30]): `f^∨` is differentiated through the recursive characterization of `C^{k,ℓ}` and a mean
  value inclusion with parameters, instead of the extension of difference quotients of `C^{1,0}`
  maps (Lemma 1.7.6).
* `Calculus/MBFrechet.lean` compares the Michal–Bastiani and Fréchet notions by an argument that
  stays in normed spaces, instead of going through the exponential law [GN26, Thm. 1.7.30].

**What is new is the formalization.** Michal–Bastiani calculus is not in Mathlib, and we are not
aware of a formalization of it in another proof assistant.

**The library rests on Mathlib.** It uses, among others:

* topological vector spaces, `LocallyConvexSpace`, von Neumann bounded sets
  (`Bornology.IsVonNBounded`), and the Hahn–Banach theorems (`SeparatingDual`,
  `geometric_hahn_banach_closed_point`);
* the interval integral and the fundamental theorem of calculus for real functions;
* the Fréchet calculus (`HasFDerivAt`, `ContDiffOn`, continuous multilinear maps), against which
  `Calculus/MBFrechet.lean` compares the Michal–Bastiani notions.

## How this library was written

[@glaroton](https://github.com/glaroton) set the mathematical program and chose the framework
and the references. He also fixed the design constraints (no `sorry`, Michal–Bastiani rather than
convenient calculus, Mathlib conventions) and reviewed the results. The Lean proofs were written
by the AI assistant Claude (Anthropic), working under his direction.

Correctness does not depend on trusting either of them:

* Lean's kernel checks every proof.
* The axiom audit below can be reproduced by anyone.
* The definitions and theorem statements are kept close to the cited literature, so they can be
  compared with it directly.

## Verification

Requirements: [`elan`](https://github.com/leanprover/elan). The Lean toolchain (`lean-toolchain`)
and the Mathlib version (`lakefile.toml`) are pinned.

```bash
lake exe cache get                  # download compiled Mathlib
lake build                          # build the library
lake env lean scripts/Axioms.lean   # print the axioms used by the main theorems
```

For every theorem, the last command should report the axioms
`[propext, Classical.choice, Quot.sound]`.
The continuous integration workflow runs the same check, and it fails if any other axiom appears,
including `sorryAx`.

## Using the library

Add the dependency to the `lakefile.toml` of a Lake project:

```toml
[[require]]
name = "lc-analysis"
git = "https://github.com/glaroton/lc-analysis"
rev = "main"
```

Then `import LocallyConvexAnalysis` loads the whole library, and a single file is imported as
`LocallyConvexAnalysis.Calculus.Rules`, etc. The declarations live in the namespace
`LocallyConvex.Analysis`.
